# Picklesware desktop app: releases

Installers for the Picklesware desktop app for Mac and Windows, by Allen Grandview LLC.

**Download:** open [the latest release](https://github.com/randyreese/picklesware-releases/releases/latest)
and choose the file for your computer:

- **Mac:** `Picklesware-<version>.dmg`. Open it, drag Picklesware to Applications, then open it
  from Applications.
- **Windows:** `Picklesware-Setup-<version>.exe`.

Once installed, Picklesware updates itself.

The app's source is not here; this repository holds only signed installers and release notes.
Picklesware apps and accounts: [picklesware.com](https://picklesware.com).
